# 十个小游戏

业余时间写着玩的，攒了十个，干脆放一个仓库里。

每个游戏都是一个单独的 HTML 文件，下载下来双击就能在浏览器里打开。不联网、不装依赖、不调任何接口，手机和电脑都能玩。右上角可以一键切换中文 / English。

## 游戏

- **提示词炼金术 / Prompt Alchemy** —— 当提示词工程师，调教一台本地"人工智障"。完成度 80 分算通关，token 超预算会被扣分。
- **失眠 / Insomnia** —— 半夜睡不着。看着念头一个个冒出来，别点开，干净地放下，把自己哄睡着。
- **凌晨四点的便利店 / The 4 AM Convenience Store** —— 便利店夜班，一晚上接待 12 位客人，听他们把心事说完。
- **中年危机模拟器 / Midlife Crisis Simulator** —— 从 35 岁活到 50 岁。事业、家庭、健康、钱包互相打架，最后看墓志铭上写什么。
- **已读不回 / Left on Read** —— 跟三个人聊天，直接打字，不用选选项。你每句话的语气都算数。
- **CodeReview地狱 / Code Review Hell** —— 在屎山代码里找 bug，躲线上事故，靠技术活着。
- **守住钱包 / Hold the Wallet** —— 塔防。你的存款，对阵 618、双 11 和黑五。
- **年会求生 / Holiday Party Survival** —— 公司聚会，喝酒、挡酒、别社死，体面活到散场。
- **租房大冒险·纽约篇 / Rent Adventure: New York** —— 在纽约待 36 个月，攒够首付。租金梯度按真实水平来的。
- **最后一份外卖 / The Last Delivery** —— 台风夜送外卖。电量、时限和顺手做的好事，顾不过来。

## 怎么玩

把 `games/` 里的 html 文件下载下来，双击用浏览器打开就行。每个游戏首页都写了规则，三十秒能看完。详细玩法在 [docs/games.md](docs/games.md)。

## 其他

- 全部原创，单文件，零依赖。
- 进度存在浏览器 localStorage 里，清缓存会丢档。
- MIT 协议，拿去改、拿去用都行。
